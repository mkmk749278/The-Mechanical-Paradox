# lib/remotion: the shared film toolkit (PLAYBOOK §8, §10)

| File | What |
|---|---|
| `brand.ts` | Colours, FEA ramp, fonts, video size, the physical spring. Generated by `scripts/brand_ts.py`; never edit by hand |
| `fonts.ts` | `loadBrandFonts()` (vendored Archivo, Inter, JetBrains Mono + Greek), `fontStacks` |
| `motion.ts` | `ease`, `tween()`, `envelope()`, `physical()` (mass 1.2, damping 24, stiffness 180), `microPush()` (1.02 → 1.05), `shudder()` |
| `gears.ts` | Exact cycloidal gear outlines, `gearWindows()`, `meshErrorDeg()` (port of `brand/gears.py`) |
| `Blueprint.tsx` | `Blueprint` (abyss, pooled light, drifting grid on the micro push), `Grain`, `Vignette`, `Atmosphere` |
| `Hud.tsx` | The live telemetry window; every row needs a `source` (claims id or `ILLUSTRATIVE`) |
| `LockedTrio.tsx` | The channel mark as a live mechanism: pen draw, solid, elastic wind-up, jam glow |
| `sfx.ts` | `SfxCue`, the foley names, `shiftCues()` |
| `three/fea.ts` | `makeFeaMaterial()`: von Mises-style stress shading with contours; analytic hotspots or a baked `stress` attribute |

Measured 2026-10-31: the FEA shader renders under `--gl=swangle`; the sting renders at 52 ms a frame at 720p60.
